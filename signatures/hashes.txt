# CAU EDR — Signature Database
# Format: HASH_TYPE|HASH|THREAT_NAME
#
# Rules for this file (enforced by scanner.LoadSignatures and by
# scanner/scanner_test.go, which fails the build if the shipped file violates
# them):
#   * HASH_TYPE is MD5, SHA1 or SHA256 and the digest has exactly 32 / 40 / 64
#     hex characters. Anything else can never match and is rejected.
#   * A digest appears at most once. Duplicates are rejected, and a digest
#     re-listed under a different threat name is reported as a conflict.
#   * Every entry must come from a public, citable source. Synthetic filler
#     (patterned digests such as a1b2c3d4...) is not allowed: it inflates the
#     count while detecting nothing.
#
# The previous revision of this file carried 53 lines: 10 digests of the wrong
# length, 2 duplicates and roughly 38 synthetic entries. Those are gone. What
# remains are the widely-published sample hashes below; keep the source
# comment with each block. Bulk ingestion from MalwareBazaar / STIX feeds
# replaces hand maintenance in a later phase (see PLAN.md, Phase 4).
